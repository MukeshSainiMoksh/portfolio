Edit CSS variables in `styles.css`:
```css

    --primary-color: #2563eb;
    --secondary-color: #10b981;
    /* ... more variables */
}
```

### Updating Content
All content is in `index.html`. Simply find the section and update the text.

### Adding Projects
Copy a `.project-card` div in the Projects section and update the content.

## 🚀 Quick Start

### 1. Preview Portfolio (No Setup Required)
Simply open `index.html` in your browser to see the portfolio.

### 2. Set Up Blog System (Optional)

**Install Dependencies:**
```bash
npm install
```

**Start API Server:**
```bash
npm start
```

**Open Portfolio:**
Open `index.html` in browser - blog will now load from API.

### 3. Add Your Profile Photo
1. Get a professional square photo (500x500px+)
2. Name it `profile.jpg`
3. Place in root folder
4. Refresh browser

**Detailed guides:**
- 📖 [Blog Setup Guide](BLOG_SETUP_GUIDE.md)
- 📸 [Profile Photo Guide](PROFILE_PHOTO_GUIDE.md)

## 🌐 Deployment

### Option 1: GitHub Pages (Free)
1. Create a GitHub repository
2. Upload these files
3. Go to Settings → Pages
4. Select main branch
5. Your site will be live at `https://yourusername.github.io/repo-name`

### Option 2: Netlify (Free)
1. Drag and drop the folder to Netlify
2. Your site is live instantly
3. Get a custom domain or use Netlify's subdomain

### Option 3: Vercel (Free)
1. Import your GitHub repository
2. Deploy with one click
3. Automatic deployments on updates

### Option 4: Traditional Hosting
Upload all files to your web hosting via FTP.
